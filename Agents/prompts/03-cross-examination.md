# Planning council — structured debate (run in EACH tool)

Read `AGENTS.md`, `docs/brief.md`, and the other agent's proposal from the linked GitHub Issue comments. No code changes.
1. Identify the TWO strongest proposals across both agents.
2. Critique the other agent's favored proposal: novelty, build-time risk, demo risk, data/API constraints, judging fit.
3. Defend or revise your own recommendation using evidence.
4. State exactly which assumption requires a quick technical spike or external verification.
5. Identify what would change your mind.
Do not fake consensus, and do not continue debating indefinitely. Finish with a concise reply formatted for a GitHub Issue comment labeled by tool/role.
