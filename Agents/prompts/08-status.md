# Project-owner status briefing

Read `docs/progress.md`, relevant open GitHub Issues, the PR list, and any latest test/deploy evidence.
Produce a concise report with:
- Current phase and milestone
- Done (with verified links/commits)
- In progress (issue/agent owner)
- Blockers and disagreements
- Decisions requiring owner approval
- Documentation updated and still needed
- Next two actions and demo readiness
Do not report a task completed merely because an agent said it completed it; check the PR/tests or mark unverified.
