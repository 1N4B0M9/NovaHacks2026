# Independent PR review

Read `AGENTS.md`, the linked GitHub Issue, approved docs, and the PR diff. Do not make implementation edits unless explicitly requested.
Look for correctness, nonfunctional demo paths, security/secrets, tests that were not truly executed, interface incompatibilities, scope creep, and stale documentation.
Report findings by severity, file and location, reproduction steps where possible, and suggested fix. Distinguish actual defects from potential risks. State whether acceptance criteria are satisfied.
Do NOT merge the PR.
