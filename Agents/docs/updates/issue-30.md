# Two-pass OCR and crop review

**Branch:** two-pass-note-review · **Issue:** #30 · **Depends on:** Chinese demo PR #29.

The scan screen defaults to Tesseract followed by the OpenRouter vision model configured on the server. The merchant selects the language on the paper separately from the UI language. Available first-pass packs: eng, spa, chi_sim, chi_tra. The same two-pass path handles every scan and cropped-line retry; single-reader selections were removed. Two-pass mode sends the selected image and Tesseract transcript to OpenRouter and requests a fresh image-based transcription, including anything the first pass missed.

A merchant can crop before transmission or crop and reread after scanning. Drag a rectangle or adjust four keyboard-accessible edges. The full original stays available for order review. Tesseract returns line bounding boxes and the weakest word confidence per line. Exact line anchors align the two transcripts. Changed wording, missing lines, [?] and low local confidence (below 75, a heuristic) trigger review. Chinese character spacing is normalized only for comparison. Flagged rows show local and online readings and a pixel crop when Tesseract located that line. A crop retry uses single-line OCR and another bounded online verification. It never confirms a line automatically. A missing first/second pass requires explicit review of every surviving line. Double failure offers manual transcription.

To test: choose 简体中文, enable 先裁剪再识别, upload tests/fixtures/chinese-order.png, select the note area and read it. Expect one E180 case and one M1 case, USD 78 total. To exercise uncertain review, use the browser fixture test for 1 case versus 2 cases. Both engines can agree on the same wrong reading or miss the same line; merchant comparison against the photo is still necessary.

Independent verification: production build passed; 47 server tests and 16 fixture browser checks passed. A real Chromium production run cropped the printed two-line note, obtained both readings for each ingredient, and approved the USD 78 simulated order. The disagreement, cropped-line retry, and approval gate were exercised using controlled browser fixtures. Handwritten accuracy and the confidence threshold require evaluation on real notes. No comparative PaddleOCR handwriting benchmark has been run.
